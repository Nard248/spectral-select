# E5 findings: information-optimal acquisition (collagen-covered NADH/FAD tissue, 8 x 31 = 248 channels)

Settings: thickness surrogate (8 grid points 0.05-1.5 mm, GCV smoothing, LOO rel. RMS 6.4 %, max 9.2 %), scale 0.25, MC fraction 0.15, ROI = 3744 full-res pixels, full protocol exposure 233 s. eps derived from sim-to-real: median RMS relative residual of 22 calibrated fits (9 collagen, 16 drops; `derive_eps`) = 6.97 % (range 5.3-9.6 %), spectral angle 6.1 deg (4.4-8.3); this is an upper bound (contains camera noise). Grid eps = 0, 0.5, 1, 2, 5 %, plus eps_ref = 7 %. Model error is added as independent per-channel variance (eps S_c)^2: optimistic if real errors are correlated across channels.

- PHOTON-LIMITED CRLB (eps = 0, all 248 channels, t = 0.6 mm): thickness alone 0.26 um; with one unknown amplitude 0.90 um; with per-excitation gains 1.05 um; thickness inside the joint (t, NADH, cover mu_s') problem 0.47 um (t = 0.9 mm, FD Jacobian). These are NOT achievable precisions.
- MODEL-ERROR-LIMITED floor (t = 0.6 mm, thickness + amplitude): 2.2 / 2.8 / 4.0 / 7.3 / 9.5 um at eps = 0.5 / 1 / 2 / 5 / 7 %: roughly linear in eps (floor ~ eps / |d ln S / dt| ~ 1.3 um per % ). already at eps = 0.5 % the floor is 2.4x (thickness + amplitude) to 4.8x (thickness alone, 1.25 um) the photon-limited value, and 10x at 7 %: precision is systematics-limited for any eps >= 0.5 %.
- Even the eps-limited floor (4-10 um) is 1-2 orders below the 25-200 um retrieval errors observed in E6: the remaining gap is model BIAS (wedge, surrogate interpolation, lateral transport), which a variance-only CRLB does not contain.
- Channels needed within 10 % of the full-protocol CRLB (greedy, thickness + amplitude, k to 248): 28 (eps = 0, 81 % exposure-time saving), 35 / 28 / 30 / 40 / 45 at eps = 0.5 / 1 / 2 / 5 / 7 % (time saving 88-94 %). Joint 3-parameter target: 13 channels photon-limited (97 % time saving), 20-27 under model error. Random subsets (median of 40 draws) and uniform subsets reach within 10 % only with ~all channels (k >= 200).
- k = 8 information-optimal (exchange-refined): 1.24 um photon-limited vs 12.6 um random median (10x) and 6.7 vs 34 um at eps = 2 % (5x).
- The optimal set CHANGES with eps (k = 8, thickness + amplitude): photon-limited picks UV-excited blue channels (310-325 nm -> 420-480 nm, median ex 317 nm, high absolute signal, mean |dS/dt| 400 e-/mm); with eps >= 0.5 % it moves to 415-430 nm excitation -> 455-570 nm (mean relative sensitivity 0.64 -> 1.28 /mm, signal 713 -> 39-94 e-). Jaccard with the eps = 0 set: 0.14 (0.5 %), 0.07 (>= 2 %). Using the photon-optimal set when eps = 2 % costs 28 um instead of 6.7 um (4.2x worse); at 7 %: 99 vs 19.5 um.
- Unsupervised channel selection (repo spectral autoencoder, k = 8, 2 seeds): 2.2-2.5 um photon-limited (2x worse than information-optimal, 5x better than random) but 39-44 um at eps = 2 % (6x worse than information-optimal, comparable to random 34 um): label-free selection keeps the photon-rich blue channels and is not robust to model error.
- Efficiency (200 ML fits per case; truth = independent simulator run, so there is surrogate bias): photon-only: SD / CRLB = 1.01, 0.99 (t = 0.25, 0.6 mm), 0.95-1.03 for k = 8; at t = 1.1 mm the surrogate-truth bias (-230 um) invalidates it (ratio 3.4, k8: 34). With eps = 2 %: 1.13 / 1.64 / 1.13 (all) and 0.99 / 1.06 / 4.2 (k8). Ratios > 1 where bias >> SD (parameter-dependent weights, local linearisation).
- Caveats: FD vs surrogate Jacobian disagree at t = 0.9 mm (FD SD 0.39 vs 0.92 um, MC noise in FD); exposure-allocation output of `optimal_design` (not used here) did not beat equal allocation in this scene; one scene, one ROI.

Take-home for the paper: photon-limited CRLBs (sub-micron) are an upper bound on information, not on achievable precision; including a calibration/model error of 0.5-7 % lifts the floor to 2-10 um and shifts the optimal channel choice from absolute-signal-rich UV channels to channels with large relative thickness sensitivity (415-430 nm excitation). About 30 of 248 channels (~12 %) deliver within 10 % of the full-protocol bound at roughly 90 % less exposure time, and information-optimal selection beats random/unsupervised selection by 5-10x at fixed k.
