## Physics (MCML-style packets generalised to planar-interface 3D layers)
- Region = layer i between planes h_{i−1}, h_i (exact planes a+bx+cz; wedges included; layers may
  thin to ZERO thickness at an edge — handle degenerate regions robustly) and four vertical side planes.
  Outside: air n=1. Bottom face (y=0) and sides: Fresnel to air; escaping light leaves (tallied on the side
  faces if within the camera acceptance, otherwise lost); bottom escape = lost (block sits on the stage).
- Step: s = −ln ξ/μt (dimensionless-step bookkeeping across interfaces like MCML), distance to the nearest
  boundary plane along the direction; interface between layers with different n → Fresnel
  reflect/refract with the PLANE normal (tilted for wedges), TIR; same n → pass through. Implicit capture
  (deposit w·μa/μt), Henyey-Greenstein scattering, Russian roulette. μs = 0 must work (clear layers).
- Excitation launch: photons start at `launch.points_local` with `dirs_local`, power-weighted (sample
  launches ∝ power, or carry power as weight — your choice, unbiased). Apply Fresnel at entry: the
  REFLECTED part is discarded (the tracer renders the glint); only transmitted light is transported.
- Tallies (excitation): absorbed power per voxel (layer-conforming: sub = floor(S·(y−h_{i−1})/(h_i−h_{i−1})));
  fluence via the track-length estimator (Σ w·ℓ / voxel volume — voxel volumes vary with local thickness:
  compute exactly); elastic radiance per face cell: when a packet escapes through a face with refracted
  direction d_out within `acceptance_half_angle_deg` of `camera_dir_local`, add w to the cell; radiance =
  W / (A_cell · Ω · cosθ_out) with Ω = 2π(1−cos θ_a), per unit launch normalisation so the result is in
  mW/(mm²·sr) for the given launch powers. Diagnostics R, T, A, specular.
- Emission: sample source voxels from q(v) = Σ_c sources[c, v] (alias table), uniform position inside the
  voxel's exact layer-conforming cell, isotropic direction; every packet carries a C-vector of weights
  sources[c,v]/q(v)·Q/N so ONE run per wavelength node serves all channels (excitations × layers × dyes).
  Optics at the node wavelength. Tally per face cell per channel within the acceptance cone (same radiance
  normalisation, per unit emitted spectral density as documented in `EmissionTallies`), plus the escaping
  light's mean source depth below the top surface and per-layer origin fractions (diagnostics).
- Determinism: fixed batch decomposition with per-batch seeds and ordered reduction ⇒ bit-identical for a
  given seed regardless of thread count (test it). float64 accumulation.
- Performance (M4 Pro, numba parallel): 40×40 mm block, 3 layers, 80×80 lateral cells, S=8:
  excitation 2e6 photons < 3 s; emission 2e6 photons with C = 24 channels < 4 s per node. Report timings.
  Cold JIT once (cache=True).

## Verification (physics credibility is the product — report each as number vs reference)
1. Single homogeneous layer, large footprint (≥ 200×200 mm), wide uniform normal beam: total diffuse
   reflectance / transmittance vs the repo's MCML engine (`transport_mc.mcml_slab`) at the MCML benchmark
   (μa=1, μs=9, g=0.75, n=1, d=0.2 mm) and a mismatched case — within ~1 %.
2. Fluorescent single layer: centre-region fluorescence radiance vs the 1D path
   `E·Σ_k μa_k Φ_k e_k · G` from `transport.get_transport_model().kernels(...)` (same optics, normal
   incidence, camera on the normal) — within ~3–5 % (both MC); same for elastic vs ρ.
3. Two identical stacked layers ≡ one layer of the summed thickness.
4. Clear cover (μs=0, absorbing) over a turbid fluorescent layer ≈ uncovered result × exp(−μa·path) ×
   Fresnel factors (compare to an analytic estimate; state tolerance).
5. Energy conservation R + T + A + specular = 1 (to MC noise / 1e-9 for the deterministic split parts).
6. Wedge sanity: at several x along a slowly varying wedge, the buried-layer fluorescence matches
   separate uniform-cover blocks of the local thickness within ~10 % (lateral transport differences are
   real — report them); signal decreases monotonically with cover thickness for a non-fluorescent turbid cover.
7. Determinism + thread invariance; zero-thickness layer edge does not produce NaN/inf.
