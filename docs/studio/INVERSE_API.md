# Inverse-problem API (v1.2): unmixing, surrogates, fits, Fisher information, design

For the web engineer. Router: `src/spectraforge/studio/routes_inverse.py` (`router`, mounted with `app.include_router(router)`; it needs `app.state.store`, `app.state.jobs`, optionally `app.state.sweeps`). JSON in, JSON out (one binary map endpoint). Errors: 404 unknown id, 422 invalid request (`detail` is a string or Pydantic issue list), 500 engine failure.

**Sync vs job.** Anything that runs the simulator (`/api/surrogates`, `/api/fisher` or `/api/design` with an `experiment`) is a **job** on the shared single worker: the response is `{job_id}`; follow it with the usual `WS/GET /api/jobs/{id}`. On `done`, the event/status field `capture_id` holds the **inverse result id**; fetch with `GET /api/inverse/results/{id}` (surrogates: `GET /api/surrogates/{id}`). Everything that only evaluates a surrogate or a stored capture is synchronous with size limits (`MAX_SIM_RUNS=128` simulator runs per job, `MAX_UNMIX_PIXELS=200000`, `MAX_MAP_TILES=20000`). Registry ids (surrogates, results) live in memory (LRU of 12).

**Parameters** (`parameters[]`): `{name?, path | paths[], mode?: "absolute"|"shift", lo?, hi?}`; paths are JSON pointers into the experiment (e.g. cover thickness `/objects/0/shape/layers/2/thickness/thickness_mm`; give both `thickness_mm` and `end_thickness_mm` in `paths` to keep a wedge's value consistent). `overrides` `{pointer: value}` are applied first (e.g. `".../thickness/kind": "uniform"` to flatten a wedge).
**ROI**: analysis ROI dict; with `"normalized": true` coordinates are fractions of the image (default: central rect 0.4-0.6). **Channels** are (excitation, emission band) pairs; `bands`: `"all"`, `{from_nm,to_nm}` or a list of band centres; `excitations`: list of nm.

Security: `cache` must be a boolean (the server always uses its own cache directory, `~/.cache/spectralforge/surrogates`); no request field names a file path.

Units: signals are **electrons** (net, dark removed); `crlb_sd` is in parameter units (mm for thickness). Variances follow the Poisson-Gaussian model documented in `surrogate.py`.

**Systematic model error (`model_error_rel`).** `surrogate.NoiseModel.model_error_rel` (epsilon, default 0 = photon/read noise only, behaviour unchanged) adds `(epsilon * S_c)^2` to every channel variance; it is not reduced by pixel averaging. `NoiseModel.with_model_error(eps)` returns a copy; `information.fisher_from_surrogate(..., model_error_rel=eps)` overrides it; `information_at_exposure` honours it; it round-trips through `to_json/from_json`. The CRLB with epsilon > 0 is a *model-error-limited* floor (channels assumed independently mis-modelled: optimistic for correlated errors); with epsilon = 0 it is the photon-limited bound and must not be quoted as achievable precision. A sensible epsilon is the RMS relative residual of the calibrated twin against real data (sim-to-real, about 5-7 %); see `publications/spectralforge_studio/experiments/C3_common.derive_eps`.
